I used PCBWay (not JLCPCB) when I ordered my Pomodoro Timer PCBs, becuase their assembly service was a bit cheaper for the setup I wanted (a blue or black PCB).

That said, the files in this directory should be "sendable" to JLCPCB. Use the following files:


* `rev1.0.1` is a .zip-file with all the gerbers

* `bom.xls` is the BOM file (for the assembly service)


* `sotpotatis_pomodoro_timer-all-pos.csv` is the positions file (for the assembly service)
